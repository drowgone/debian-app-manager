Менеджер внешних приложений — это графическое приложение на PySide6
для Linux-систем на базе Debian/Ubuntu, предназначенное для просмотра,
запуска, обновления и удаления установленных приложений, импорта
AppImage-файлов и управления записями автозапуска — всё из одного места.

Приложение распознаёт APT, Snap, Flatpak, AppImage и вручную
установленные программы как отдельные источники. Интерфейс адаптируется
под окружения рабочего стола Linux, автоматически применяет светлую и
тёмную темы и настроен на чёткое отображение на дисплеях с High-DPI.

## Основные возможности

- Просмотр установленных приложений по источникам: APT, Snap, Flatpak,
  AppImage и приложения, установленные вручную
- Поиск приложений по названию и фильтрация по источнику
- Отображение сведений о приложении: версия, размер, источник и дата
  установки
- Безопасный запуск, обновление и удаление приложений
- Импорт `.AppImage`-файлов, придание им прав на исполнение и создание
  ярлыков рабочего стола
- Управление приложениями, запускающимися автоматически при включении
  компьютера
- Краткая информация о времени загрузки системы и службах, занимающих
  больше всего времени при старте
- Выборочная очистка кеша APT, неиспользуемых зависимостей, остатков
  Flatpak runtime и журналов
- Отображение ошибок и предупреждений на отдельной вкладке
- Фоновые обработчики (worker) и анимации интерфейса для процессов
  сканирования, обновления и очистки
- Чёткий текст, значки и настройки масштабирования для дисплеев с High-DPI

## Вкладки интерфейса

### Приложения

В этом разделе отображается общий список приложений в системе. Есть
поле поиска, фильтр по источнику и счётчик количества приложений.
В каждой строке приложения показаны название, метка источника и кнопки
доступных действий.

### Автозапуск

Этот раздел управляет приложениями, которые открываются автоматически
при запуске компьютера. Считываются записи автозапуска уровня
пользователя и уровня системы. Системные записи напрямую не
изменяются — при необходимости пользователь управляет ими через файл
переопределения (override).

### Очистка

Этот раздел помогает выборочно очищать кеш и остаточные файлы,
накапливающиеся со временем. Процесс очистки отображается в панели в
стиле терминала.

### Ошибки

В этом разделе собираются проблемы, возникшие во время сканирования,
обновления, удаления или очистки. Это помогает пользователю быстро
понять, в каком источнике или команде возникла проблема.

## Системные требования

- Debian 12+ или Ubuntu 22.04+ на базе рабочего стола Linux
- Python 3.10 или новее
- `pkexec` и polkit
- PySide6
- Опционально: `snapd`
- Опционально: `flatpak`
- Опционально: `systemd-analyze`

## Установка

Клонирование из GitHub:

```bash
git clone https://github.com/<username>/debian-app-manager.git
cd debian-app-manager
```

Создание виртуального окружения:

```bash
python3 -m venv venv
source venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Чтобы добавить в меню рабочего стола:

```bash
./install.sh
```

`install.sh` создаёт `.desktop`-файл для текущего пользователя и
позволяет запускать приложение из меню рабочего стола.

## Запуск тестов

Установка зависимостей для разработки:

```bash
pip install -r requirements-dev.txt
```

Выполнение тестов:

```bash
pytest tests/ -v
```

Краткий вывод:

```bash
pytest tests/ -q
```

Текущее состояние тестов:

```text
87 passed
```

## Основные модули

- `core/scanner.py` — собирает установленные приложения из различных
  источников
- `core/remover.py` — безопасно удаляет приложения в зависимости от их
  источника
- `core/updater.py` — управляет операциями обновления APT, Snap и Flatpak
- `core/autostart.py` — считывает и изменяет записи автозапуска
- `core/appimage_manager.py` — выполняет импорт и удаление AppImage
- `core/cleaner.py` — подготавливает команды очистки системы
- `gui/main_window.py` — строит основное окно PySide6 и вкладки
- `gui/theme.py` — задаёт цвета, шрифты, настройки High-DPI и стили
- `gui/layout_helpers.py` — хранит переиспользуемые компоненты интерфейса

## Подход к безопасности

Приложение спроектировано таким образом, чтобы аккуратно выполнять
операции, влияющие на систему.

- Вызовы subprocess выполняются с `shell=False`
- Операции, требующие прав root, выполняются через `pkexec`
- `sudo` напрямую не используется
- Системные файлы автозапуска напрямую не изменяются
- Автоматическое удаление файлов в системных каталогах ограничено
- Применяются проверки symlink и реального пути
- Перед опасными операциями, такими как удаление или очистка,
  показывается диалог подтверждения

## Устранение неполадок

### PySide6 не найден

Убедитесь, что виртуальное окружение активировано:

```bash
source venv/bin/activate
pip install -r requirements.txt
```

### `pkexec` не работает

Проверьте, установлен ли polkit:

```bash
pkexec --version
```

В сессии рабочего стола должен быть запущен агент аутентификации polkit.

### Приложения Snap или Flatpak не отображаются

Проверьте, установлен ли соответствующий сервис или CLI:

```bash
snap version
flatpak --version
```

Если эти инструменты не установлены, приложение продолжает работать с
остальными источниками.

### Приложение не отображается в меню рабочего стола

Запустите `install.sh` заново:

```bash
./install.sh
```

Затем может потребоваться перезагрузить окружение рабочего стола или
выполнить выход и повторный вход в систему.
